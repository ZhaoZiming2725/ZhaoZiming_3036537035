# Generated tables

Run `python code/run_all.py` from the repository root. All numeric CSVs here are generated by `code/analysis.py`, without manual edits.

| File | Purpose |
|---|---|
| `table2_means_all_variables.csv` | All Table 2 variables, means, SEs, sample counts and NJ-PA tests |
| `table2_comparison.csv` | Computed means versus printed Table 2 values |
| `table3_means.csv` | Five rows and eight groups/contrasts of Table 3 |
| `table3_comparison.csv` | All 40 point estimates versus printed values |
| `table4_did_regression.csv` | Five assigned 357-store models, OLS/HC3 SEs and diagnostics |
| `table4_ownership_sensitivity.csv` | Ownership-inclusive alternative to author-code model v |
| `figure1_wage_bins.csv` | Bin counts, denominators and percentages for Figure 1 |
| `table_extension_ownership.csv` | Franchise/company NJ-PA contrasts and interaction, with HC3 intervals |
| `extension_group_audit.csv` | Ownership by state cell counts and mean employment changes |
| `extension_sample_sensitivity.csv` | Ownership interaction using the 384-store employment-only sample |

Table 3 row-3 standard errors are intentionally blank because they were not reconstructed. The report explains remaining source differences and inference limitations. `outputs/validation.json` records sample checks and the raw-input checksum.
